### 📦 Repository Architecture & Subfolder Structure

The repository is modularized into distinct subfolders for clear separation of concerns:

- **`/dashboard`** — Next.js 15 + React + Tailwind CSS web application (decoupled static build served live on Vercel).
- **`/src`** — Python ETL pipeline source code (`pipeline.py`, `profiler.py`, `cleaning/`, `analytics/`).
- **`/tests`** — Pytest test suite with 27 unit & integration tests covering edge conditions and SQL analytics.
- **`/output`** — Data artifacts generated by the pipeline (`warehouse.db`, `quarantine/*.csv`, `profile_report.json`).
- **`/submission_pack_jeff_davison`** — Submission documentation, executive summary, and deployment guides.

### 🚀 Bonus Feature: Live Interactive Web Application

Located in the **`/dashboard`** subfolder and hosted live at **[https://karl-david-mindex-challenge3.vercel.app](https://karl-david-mindex-challenge3.vercel.app)**, this web app provides an interactive evidence dashboard for code review.

#### What the Web Application Conveys:
1. **Interactive Defect Explorer**: Every single one of the 17 defect classes (`ST-01` through `TX-10`) is mapped with its severity, detected vs. expected counts, decision rationale, quarantine status, and direct line-number links to the underlying Python implementation (`src/cleaning/*.py`).
2. **Data Profile & Lineage**: Visualizes pre- and post-cleaning metrics, raw vs. clean row reconciliations, null percentages, and step-by-step transformation lineage.
3. **Data Warehouse Schema & SQL Runner**: Displays the full 5-table Star Schema ERD alongside executable SQL queries and live result sets for all 5 business analytics questions.
4. **Test Suite Proof & Revenue Tie-Out**: Live display confirming the **27/27 Pytest pass rate** and the **$0.00 revenue reconciliation delta**.
5. **Interview Copilot Widget**: An interactive AI assistant embedded directly in the UI for technical Q&A during interview walkthroughs.
