### 🚀 Bonus Feature: Live Interactive Review Dashboard

In addition to the pipeline and warehouse, I built and deployed a production-grade web application in the **`/dashboard`** subfolder, hosted live at **[https://karl-david-mindex-challenge3.vercel.app](https://karl-david-mindex-challenge3.vercel.app)**.

#### What the App Conveys & Features:
1. **Interactive Defect Explorer**: Maps every single one of the 17 defect classes (`ST-01` through `TX-10`) with its severity, detected vs. expected counts, decision rationale, quarantine status, and direct line-number links to the underlying Python implementation (`src/cleaning/*.py`).
2. **Data Profile & Lineage**: Visualizes pre- and post-cleaning metrics, raw vs. clean row reconciliations, null percentages, and step-by-step transformation lineage.
3. **Data Warehouse Schema & SQL Runner**: Displays the full 5-table Star Schema ERD alongside executable SQL queries and live result sets for all 5 business analytics questions.
4. **Test Suite Proof & Tie-Out Proof**: Live display confirming the **27/27 Pytest pass rate** and the **$0.00 revenue reconciliation delta**.
5. **Interview Copilot & Reviewer Guide**: Includes an embedded AI assistant widget designed for interactive Q&A and technical walkthroughs during code review.
